# PewPew Cloud Client — راهنما

این مخزن متعلق به کلاینت PewPew Cloud است که بر پایه Clash Verge Rev و Tauri ساخته شده است. مستندات فعلی به زبان چینی ساده و انگلیسی نگهداری می‌شوند.

در تاریخ ۲۰۲۶-۱۰-۰۸، بسته فعلی نسخه آزمایشی داخلی و بدون امضا برای Windows x64 با شماره 0.1.4 است و نسخه پایدار محسوب نمی‌شود. مشکلات نصب و خروج گزارش شده‌اند؛ پیش از آزمایش محدودیت‌ها را بخوانید. نسخه قدیمی `autobuild` فقط برای سابقه نگهداری شده است.
