# PewPew Cloud Client — Guía

Este repositorio contiene el cliente de PewPew Cloud, basado en Clash Verge Rev y Tauri. La documentación actual se mantiene en chino simplificado e inglés.

A fecha de 2026-10-08, el paquete actual es una versión de prueba interna sin firma para Windows x64 (0.1.4), no una versión estable. Se han comunicado problemas de instalación y de cierre; consulta las limitaciones antes de probarlo. La versión antigua `autobuild` se conserva solo como referencia histórica.
