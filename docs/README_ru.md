# PewPew Cloud Client — Руководство

Этот репозиторий содержит клиент PewPew Cloud на основе Clash Verge Rev и Tauri. Актуальная подробная документация поддерживается на упрощённом китайском и английском языках.

На 2026-10-08 текущий пакет — неподписанная внутренняя тестовая версия 0.1.4 для Windows x64, а не стабильный выпуск. Сообщалось о проблемах установки и завершения работы; перед тестированием прочитайте ограничения. Старый `autobuild` сохранён только для истории.
