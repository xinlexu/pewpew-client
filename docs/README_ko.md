# PewPew Cloud Client — 안내

이 저장소는 Clash Verge Rev와 Tauri를 기반으로 하는 PewPew Cloud 클라이언트입니다. 현재 상세 문서는 중국어 간체와 영어로 관리합니다.

2026-10-08 기준 현재 배포물은 Windows x64용 서명되지 않은 내부 테스트 버전 0.1.4이며 안정 버전이 아닙니다. 설치 및 종료 문제가 보고되었으므로 테스트 전에 제한 사항을 확인하세요. 이전 `autobuild`는 기록용으로 보관합니다.
