# PewPew Cloud Client — ガイド

このリポジトリは Clash Verge Rev と Tauri を基盤とする PewPew Cloud クライアントです。現在の詳細なドキュメントは簡体字中国語と英語で管理しています。

2026-10-08 時点の配布物は Windows x64 向けの署名なし内部テスト版 0.1.4 であり、安定版ではありません。インストールや終了時の問題が報告されているため、テスト前に制限事項を確認してください。旧 `autobuild` は履歴参照用です。
